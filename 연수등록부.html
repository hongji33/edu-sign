📱 서명 등록 설정 방법 (처음 1회)

각자 폰으로 서명받아 내 구글 시트에 자동 저장되게 하는 설정입니다.
  1. 구글 시트 만들기 — 구글 드라이브에서 새 구글 시트를 하나 만듭니다.
  2. 코드 넣기 — 확장 프로그램 → Apps Script를 열고, 기존 내용을 지운 뒤 아래 ‘코드 복사’ 코드를 붙여넣고 저장합니다.
  3. 배포 — 배포 → 새 배포 → 유형 ‘웹 앱’, 실행 대상 ‘나’, 액세스 ‘모든 사용자’로 배포하고 권한 허용.
  4. 주소 복사 — 나온 웹 앱 URL(.../exec)을 복사합니다.
  5. 붙여넣기 — 위 설정의 ‘① 내 구글시트 저장 주소’ 칸에 붙여넣으면 끝!
↓ 붙여넣을 코드 (연수명별 탭 자동 분리)

      
⚠️ 일부 학교·교육청 구글 계정은 앱스스크립트 배포가 막혀 있을 수 있어요. 그럴 땐 개인 구글 계정으로 만드세요. 개인정보가 모이니 시트·드라이브 폴더 공유는 본인만 보도록 두세요.
